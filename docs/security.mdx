ریالیتی طوری طراحی شده که داده‌های مالی روی دستگاه شما بماند. برای لایه اضافه، می‌توانید **پین** بگذارید.

## فعال‌سازی پین

1. صفحه تنظیم پین را از مسیر امنیتی اپ باز کنید.
2. یک پین قابل‌یادآوری انتخاب کنید.
3. پین را دوباره وارد کنید تا تأیید شود.
4. از این به بعد، هنگام باز کردن اپ (طبق تنظیم) پین درخواست می‌شود.

## نکات امنیتی

- پین را با دیگران به اشتراک نگذارید.
- از پین‌های خیلی ساده مثل `۱۲۳۴` پرهیز کنید.
- اگر پین را فراموش کردید، مسیر بازیابی به نسخه اپ بستگی دارد — قبل از تعویض دستگاه از [مدیریت داده](/docs/data-management) پشتیبان بگیرید.

## حریم خصوصی به زبان ساده

- تراکنش‌ها روی گوشی شما ذخیره می‌شوند.
- ریالیتی مدل درآمدش را روی **اشتراک** بنا می‌کند، نه فروش داده مالی.
- مربی هوشمند فقط وقتی لازم است و با دسترسی مناسب، خلاصه داده را برای راهنمایی استفاده می‌کند — ببینید [مربی هوشمند](/docs/ai-coach).
